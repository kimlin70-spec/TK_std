# 사진 주석 도구 (PhotoAnnotator)

사진 위에 화살표·네모·번호·코멘트를 달아 PNG로 저장하는 윈도우용 도구입니다.
결과 이미지를 ChatGPT·Claude에 보여 주며 수정 지시를 내리는 용도라, 표시와 글씨가 어떤 사진 위에서도 또렷하게 보이도록 만들었습니다.

- Tauri 2 + TypeScript + Konva.js
- 브랜치에 푸시할 때마다 GitHub Actions(windows-latest)가 설치 없이 바로 실행되는 exe를 만듭니다.

## exe 받기

1. 저장소의 **Actions** 탭 → 최신 **Build Windows exe** 실행(초록 체크)을 엽니다.
2. 페이지 아래 **Artifacts**에서 `PhotoAnnotator-windows`를 내려받아 압축을 풉니다.
3. `PhotoAnnotator.exe`를 그대로 실행합니다. 설치는 없고, Windows 10/11에 기본 포함된 WebView2 런타임을 사용합니다.
   처음 실행 시 SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 누르세요.

## 사용법

| 동작 | 방법 |
| --- | --- |
| 사진 불러오기 | `Ctrl+V`(캡처 붙여넣기) · 파일 끌어다 놓기 · **열기**(`Ctrl+O`) |
| 보기 | 마우스 휠로 확대·축소, 빈 곳을 드래그하면 이동 |
| 화살표 | **화살표** 선택 후 드래그 — 시작점에 글상자, 끝점에 가늘고 뾰족한 화살촉 |
| 네모 | **네모** 선택 후 드래그 — 테두리만 표시, 바깥 모서리에 글상자가 생기고 선으로 연결 |
| 글상자 | **글상자** 선택 후 클릭한 곳에 입력 |
| 번호 | 화살표·네모마다 ①②③ 자동 부여, 글상자 맨 앞에도 같은 번호. 하나를 지우면 다시 정렬 |
| 글 입력 | 생기자마자 바로 입력(한글 가능). `Enter` 줄바꿈, `Esc`·바깥 클릭으로 완료, 더블클릭으로 다시 수정 |
| 선택·이동 | **선택** 도구로 클릭 후 드래그. 글상자만 옮기면 연결선이 따라옴 |
| 크기 조절 | 네모는 모서리 핸들, 화살표는 끝점 핸들을 드래그 |
| 삭제 | 선택 후 `Del` |
| 실행취소 / 다시실행 | `Ctrl+Z` / `Ctrl+Y` |
| 저장 (`Ctrl+S`) | 주석을 합성한 PNG를 원본 해상도로 저장. 파일에서 연 사진은 원본 옆에 `이름_주석.png`, 붙여넣은 사진은 저장 위치를 물은 뒤 `이름_주석.png`와 `이름_원본.png`를 함께 저장 |
| 복사 (`Ctrl+Shift+C`) | 주석 합성 이미지를 클립보드로 복사 → ChatGPT·Claude 입력창에 바로 붙여넣기 |

표시 색은 형광 마젠타 + 흰 외곽선, 글상자는 흰 배경·검은 글씨이며, 선 굵기와 글씨 크기는 사진 크기에 비례해 자동으로 정해집니다.

## 개발

```bash
npm install
npx tauri icon src-tauri/app-icon.svg --output src-tauri/icons   # 아이콘 생성(최초 1회)
npm run tauri dev                                                 # Rust 툴체인 필요
```

```bash
npm run build && npm run check:browser   # Playwright로 브라우저에서 동작 확인
```
